# Соборова світлиця

Сайт кав'ярні «Соборова світлиця» ([Instagram](https://www.instagram.com/soborova.svitlytsya/)).

Статичний односторінковий сайт: `index.html`, без збирання. Щоб переглянути локально, відкрийте файл у браузері.

Перед запуском замініть дані-приклади: адресу, години роботи, телефон, меню (масив `MENU` у скрипті внизу `index.html`) і фото в розділі «Атмосфера».
