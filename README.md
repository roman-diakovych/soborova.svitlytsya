# Соборова світлиця

Сайт «Соборової світлиці», простору живої парафії в укритті Патріаршого собору УГКЦ ([Instagram](https://www.instagram.com/soborova.svitlytsya/)).

Статичний односторінковий сайт без збирання: `index.html` і фото в `images/`.

Сайт працює на Railway. Сервіс `site` бере файли прямо з гілки `main` цього репозиторію, тож після пушу зміни з'являються на сайті протягом кількох хвилин.
